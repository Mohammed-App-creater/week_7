# Task 4: Interactive User Interface

## 🖥️ Overview
Task 4 provides the frontend for the RAG system. It exposes a Streamlit-based web dashboard that allows users to query the complaint database, view synthesized answers, and inspect the original retrieved source documents for verification.

## 🌟 Features
- **Query Input:** Simple chat interface for natural language questions.
- **RAG Generation:** Displays the answer generated by the `flan-t5-base` model.
- **Source Inspection:** Expandable section to view the top-k retrieved documents used to generate the answer.
- **Parameter Tuning:** Sidebar controls to adjust:
    - `k` (Number of retrieved documents).
    - `Max Token Length` (Length of generated answer).
- **History Management:** "Clear Conversation" button to reset the session.

## 🛠️ Tech Stack
- **Framework:** Streamlit
- **Backend Integration:** Direct import of `src.rag_pipeline`.

## 🚀 How to Run
From the **project root directory**, execute:

```bash
streamlit run ui/app.py
```

*Note: The app expects to be run from the root so it can resolve the `src` package.*

## 📸 Usage
1.  **Launch the App:** Open the URL provided in the terminal (usually `http://localhost:8501`).
2.  **Wait for Load:** The pipeline (embedding model & LLM) loads into memory on startup (green success message).
3.  **Ask a Question:** Type "What are common issues with student loans?"
4.  **View Results:** Read the summarized answer and expand "Retrieved Sources" to see the raw complaint text.
